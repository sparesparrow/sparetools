## Quick Start Guide

### Building CSI Tools

```bash
# Intel 5300 CSI Tool
cd research/repositories/linux-80211n-csitool
make
sudo make install
```

```bash
# Atheros CSI Tool
cd research/repositories/Atheros-CSI-Tool
chmod +x setup.sh
./setup.sh
```

### Running Examples

```bash
# WiFi CSI Sensing Framework
cd research/repositories/WiFi-CSI-Sensing
python3 main.py --interface wlan0
```
